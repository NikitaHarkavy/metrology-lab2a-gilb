CL — абсолютная сложность: число условных операторов. Считаются if и каждая ветвь elif, циклы for и while, каждая ветвь case оператора match, условное выражение a if c else b, а также for и if внутри генераторов списков.

Селектор match и ветвь по умолчанию case _ условиями не являются; else (у if и у циклов) отдельным условием не считается.

N — общее число операторов: присваивания, вызовы функций, return, break, continue, pass, import и т. п., а также по одному оператору if, elif, for, while, match, try, with. Не считаются else, case, except, finally, объявления def/class, декораторы и строки документации.

cl = CL / N — относительная сложность (насыщенность программы условными операторами).

CLI — максимальный уровень вложенности условного оператора. Оператор match заменяется вложенными друг в друга условиями (каждая следующая ветвь case вложена в предыдущую), ветвь elif вложена в предыдущий if. Условный оператор, не вложенный ни в одно условие, имеет уровень 0.
