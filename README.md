|---|---|
| Абсолютная сложность CL | 20 |
| Общее число операторов N | 49 |

| Максимальный уровень вложенности CLI | 5 |

## Правила подсчёта

**CL** — число условных операторов:
- `if` и каждая ветвь `elif`;
- циклы `for` и `while`;
- каждая ветвь `case` оператора `match`, кроме ветви по умолчанию `case _`;
- условное выражение `a if c else b`;
- `for` и `if` внутри генераторов списков.

Селектор `match`, `else` и `case _` условиями не являются.

**N** — число операторов:
- по одному на каждый простой оператор: присваивание, вызов, `return`, `break`, `pass`, `import`;
- по одному на заголовок `if`, `elif`, `for`, `while`, `match`, `try`, `with`.

Не считаются `else`, `case`, `except`, `finally`, объявления `def`/`class` и строки документации.

**CLI** — максимальный уровень вложенности условного оператора:
- `match` заменяется цепочкой вложенных `if`: каждая следующая ветвь `case` вложена в предыдущую;
- `elif` вложен в предыдущий `if`;
- условие верхнего уровня имеет уровень 0.

Это согласуется с методичкой: оператор выбора с n ветвями даёт n − 1 условий с вложенностью n − 2.
